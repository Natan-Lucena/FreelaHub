# Decisões arquiteturais

Registro das decisões arquiteturais do FreelaHub no formato ADR (Architecture Decision Record). Cada registro descreve o contexto, a decisão tomada, as alternativas consideradas e as consequências.

|---|---|---|---|
| [ADR-001](ADR-001-arquitetura-hexagonal.md) | Adoção da Arquitetura Hexagonal | Aceita | Equipe |

| [ADR-003](ADR-003-comunicacao-rest-json.md) | Comunicação REST/JSON entre frontend e API | Aceita | Emilly Paiva |
| [ADR-004](ADR-004-notificacoes-simuladas.md) | Notificações por porta e adaptador simulado | Aceita | Natan Lucena |
| [ADR-005](ADR-005-postgresql.md) | PostgreSQL e modelo relacional | Aceita | Matheus Rodrigues |
| [ADR-006](ADR-006-pagamento-escrow-simulado.md) | Pagamento em escrow com gateway simulado | Aceita | Enzo Hariel |

Novas decisões devem seguir a numeração sequencial. Uma decisão substituída não é apagada: o status passa para "Substituída por ADR-XXX".
